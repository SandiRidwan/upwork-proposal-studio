# Sample job post

Use this to try the studio without waiting for a real lead. It is a composite, not a
real client.

---

We need someone to scrape product data from a large e-commerce site.

We tried Scrapy and a couple of freelancers but we keep getting blocked. The site uses
Cloudflare and we need about 20,000 products with price, title, description and image
URLs. Output to CSV or Google Sheets. Ongoing if it works well. Budget is modest but
we are realistic, and we need it done this week if possible.

One extra thing: we want to check our prices against theirs weekly, so whatever you
build needs to keep running without us babysitting it.

---

**Expected shape of the result**

- Niche: `A` (anti-bot / hard-target scraping), with a secondary pull to `B`
  (the "keep running without us babysitting" line).
- Failure mode: "They tried scraping and the target blocked them."
- Urgency: high (so the short variant is the default).
- Client type: unspecified -> "serial" pull from "ongoing".
- One true observation: needs `[ADD: ...]` or a real detail about the target site.
- Panel: the Scroller should be OPEN if the opener names the blocking problem; the
  Skeptic is UNSURE without a real number in the text.
